Проект состоит из папок:

1. **best_npm_config** - содержит части каскада, которые являлись лучшими среди прошлых
2. **neuro_physical_model** - содержит файл для обучения всего каскада и файл построения графиков-статистик
3.  **SetVelocity_To_RealVelocity** - содержит файл для обучения **промежуточной** модели предсказывать реальную скорость с учетом заданной и типа поверхности
4. **RealVelocity_To_Current** - содержит файл для обучения  **промежуточной** модели предсказывать токи в обмотках двигателя с учетом реальной скорости и типа поверхности
5. **Currents_To_Slippage** - содержит файл для обучения  **промежуточной** модели предсказывать проскальзывания колес с учетом тока, реальной скорости и поверхностей
6. **Slippage_To_DeltaCoords** - содержит файл для обучения  **промежуточной** модели предсказывать дельта-координаты по скоростям, проскальзыванию и поверхностям
7. **RNN** - содержит файл для обучения **промежуточной** модели искать реальную координату робота по всем ранее найденным на стадиях параметрам
8. **experiment** - содержит файл для построения графика результатов авторегрессии для последнего слоя при идеальных входных данных
9. **testing_trajectories** - содержит файл для апробации модели на тестовых траекториях (круг и квадрат). Построение графиков всех переменных, предсказываемых моделью, в сравнении с идеальными

Порядок работы:
1. Обучить **промежуточные модели** (Train&Valid&Test.py). При необходимости, запустить скрипты типа stats.py для построения сравнительных графиков)
2. Запустить в neuro_physical_model дообучение (скрипт Train&Valid&Test.py), поменяв пути до файлов .pth (подобранные весовые коэффициенты и другие гиперпараметры моделей)
3. При необходимости проверки на неизвестных данных запустить testing_trajectories (На данной выборке модель не обучалась)
4. Для построения графика авторегрессии запустить trt.py в experiment для X и Y или spec_for_ang.py для Phi (Фи раскладывается на предсказание двух переменных)
